## Adding files

1. Open a site from the **Sites** tab.
2. Scroll to the **Files** section and tap **Add File**.
3. The system file picker opens — navigate to the file you want to attach.
4. Tap the file to import it.

The file appears in the Files section of the site immediately.

{: .note }
If a file cannot be imported, OnSite shows a **FILE IMPORT ERROR** alert with a description of what went wrong. This usually means the file is inaccessible or in an unsupported format.

---

## Supported file types

OnSite accepts any file that iOS can access through the Files picker, including:

- PDF documents
- Images (JPG, PNG, HEIC)
- Word documents (.docx)
- Spreadsheets (.xlsx)
- Text files (.txt)
- Any other file type available through the iOS Files app

---

## Previewing a file

1. Open a site and scroll to the **Files** section.
2. Tap a file to preview it using the built-in iOS viewer.

For files that cannot be previewed inline, tap **Open In…** to send the file to another app that supports it.

---

## Deleting a file

1. Open a site and scroll to the **Files** section.
2. Long-press the file to reveal the context menu.
3. Tap **Delete File**.

{: .warning }
Deleting a file is permanent. Make sure you have a copy elsewhere if you need it.
